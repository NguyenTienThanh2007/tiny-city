# Visual World 3.0 — Asset licensing

| Asset | Origin | Licence |
|---|---|---|
| `public/art/vw3/*.webp` (3.0A shipped `.png`), `*.json`, `manifest.json` | Generated by this repository's bake (`node scripts/art/bake.mjs`) from the procedural models in `scripts/art/assets/` | Same as the TINY CITY repository. Original work, no third-party art. |
| Models, palette, kit (`scripts/art/**`) | Written for TINY CITY | Same as the repository |
| Three.js `0.186.1` (devDependency, bake only) | npm `three` | MIT. Not shipped in the game bundle. |
| `RoomEnvironment`, `GTAOPass`, `RoundedBoxGeometry`, `EffectComposer` | `three/examples/jsm` (part of the npm package) | MIT. Used only at bake time. |
| Terrain, lighting, vector fallback art | Procedural code in `src/game/` | Same as the repository |

No textures, models, fonts or images were downloaded or traced. The reference images in the brief set the quality
bar only. No buildings, characters, signage or layouts from any existing game were reproduced. Shop signs carry
abstract gold bars rather than words or logos. Since 3.0B, signs carry short **original** names drawn with system fonts at bake time (BAKERY, SURF, BOOKS, GELATO, MARKET, STYLE, CAFÉ, FLOWERS, HARBOUR MALL, LAGOON MALL, TIDE, NOVA, HELIX, SEABREEZE, MARINA, CORAL, GARDEN CLUB, LIDO, SPLASH, …). No brand names or logos are used.
